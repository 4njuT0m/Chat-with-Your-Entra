### Legacy authentication is not blocked
- **Finding:** Legacy authentication is not blocked
- **Severity:** High
- **Evidence:**
  - security_defaults_enabled: false
  - enabled_policies_blocking_legacy_auth: (none)
  - Reported Conditional Access policies present: L1-Phishing-Resistant-MFA, L1-Block-AdminPortals-Outside-DE
- **Why it is a risk:** Legacy authentication protocols do not support modern authentication protections and can be abused by attackers to bypass MFA or automate credential stuffing.  
- **How to fix:** Create a Conditional Access policy: Users = All users (exclude emergency access accounts); Target resources = All resources; Conditions > Client apps = Exchange ActiveSync clients and Other clients; Grant = Block access. Start in Report-only, review the impact, then turn it On. Tenants without Conditional Access licences can turn on security defaults instead.  
- **Reference:** https://learn.microsoft.com/en-us/entra/identity/conditional-access/policy-block-legacy-authentication
